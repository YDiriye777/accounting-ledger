
# Small Business Accounting Ledger

**Year Up United - Capstone Project 1**

## About the Project

This is a simple Java application that helps users keep track of business income and expenses.

The program runs in the console and allows users to add deposits, make payments, view transactions, and generate reports.

## Features

- Add deposits (positive amounts)
- Record payments (negative amounts)
- Save transactions to a CSV file
- View all transactions, newest first
- View deposits only
- View payments only
- View month-to-date transactions
- View previous month transactions
- View year-to-date transactions
- View previous year transactions
- Search transactions by vendor

## Technologies Used

- Java
- IntelliJ IDEA
- Git and GitHub
- CSV file storage

## How to Run the Application

1. Download or clone this repository.
2. Open the project in IntelliJ IDEA.
3. Open `src/Main.java`.
4. Run the `Main` class.
5. Use the console menu to select an option.

The application reads and saves transactions in a file named `transactions.csv` in the project folder.

## Main Menu

D - Add Deposit  
P - Make Payment  
L - View Ledger  
X - Exit

## Ledger Menu

A - All Transactions  
D - Deposits

## Reports Menu
